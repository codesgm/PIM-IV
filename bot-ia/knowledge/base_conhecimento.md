# Base de Conhecimento - MidTalk

## Sobre o MidTalk

O MidTalk é um sistema integrado de gestão de chamados e suporte técnico desenvolvido para empresas que precisam de um atendimento eficiente e organizado.

### Principais Funcionalidades

- **Sistema de Chamados**: Criação, acompanhamento e resolução de tickets
- **Chat em Tempo Real**: Comunicação direta entre usuários e técnicos
- **FAQ Público**: Site com perguntas frequentes e chat widget
- **Atribuição Automática**: Distribuição inteligente de chamados para técnicos
- **Relatórios**: Dashboards e métricas de atendimento

## Como Usar o Sistema

### Para Usuários (FAQ)

1. **Acessar o FAQ**: Visite o site público do MidTalk
2. **Buscar Respostas**: Use a busca ou navegue pelas categorias
3. **Iniciar Chat**: Clique no ícone de chat no canto inferior direito
4. **Identificação**: Informe seu nome e email
5. **Fazer Pergunta**: Digite sua dúvida no chat
6. **Aguardar Resposta**: Um técnico será automaticamente atribuído

### Para Técnicos (Sistema Interno)

1. **Login**: Acesse com email e senha
2. **Dashboard**: Visualize chamados pendentes
3. **Atender Chat**: Clique em um chamado para responder
4. **Resolver**: Marque como resolvido quando finalizar

## Perguntas Frequentes

### Como criar um chamado?
Acesse o site FAQ e clique no ícone de chat. Informe seus dados e descreva o problema.

### Como acompanhar meu chamado?
Após criar o chamado, você receberá um ID. Use-o para acompanhar o status.

### Quanto tempo demora para resposta?
Nosso tempo médio de resposta é de 15 minutos durante horário comercial.

### Posso anexar arquivos?
Atualmente o sistema suporta apenas mensagens de texto.

### Como alterar meus dados?
Entre em contato com o suporte para alteração de dados cadastrais.

### O sistema funciona 24h?
O sistema está disponível 24h, mas o atendimento humano é das 8h às 18h.

## Procedimentos de Suporte

### Problemas Comuns

**Login não funciona**
- Verificar email e senha
- Limpar cache do navegador
- Tentar em modo anônimo

**Chat não carrega**
- Verificar conexão com internet
- Atualizar página
- Verificar se JavaScript está habilitado

**Não recebo respostas**
- Verificar se o chat está ativo
- Aguardar atribuição de técnico
- Verificar se não há bloqueio de pop-ups

### Escalação de Problemas

1. **Nível 1**: Problemas básicos de uso
2. **Nível 2**: Problemas técnicos complexos
3. **Nível 3**: Problemas de infraestrutura
