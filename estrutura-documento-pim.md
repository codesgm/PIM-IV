## Diretrizes Importantes

### ✅ Fazer
- Seguir rigorosamente a formatação ABNT
- Evidenciar a contribuição de cada disciplina
- Incluir referências a livros (obrigatório)
- Documentar todos os diagramas e códigos
- Apresentar evidências de funcionamento
- Mostrar prompts de IA utilizados

### ❌ Evitar
- Explicar conceitos básicos (ex: "Um diagrama de classes é...")
- Usar tecnologias diferentes das especificadas
- Deixar códigos sem comentários
- Esquecer de mapear disciplinas aos conteúdos

### Disciplinas Contempladas
- **Base**: Projeto de Sistemas OO, Tópicos Especiais POO, POO II, Desenvolvimento Web, Gerenciamento de Projetos
- **Complementar**: Gestão da Qualidade, Empreendedorismo, Relações Étnico-Raciais

### Tecnologias Obrigatórias
- **Desktop**: C# com Windows Forms/WPF/Blazor
- **Web**: ASP.NET Core com C#
- **Mobile**: Android
- **Banco**: MS SQL Server (obrigatório)
- **IA**: Ferramentas generativas para FAQ e suporte

## Observações Finais
- A estrutura segue uma abordagem **top-down**: do conceitual para o técnico
- Qualquer leitor pode parar no nível de detalhe necessário
- Todos os critérios de avaliação estão explicitamente mapeados
- O foco está na solução do problema empresarial, não em explicações teóricas
